# Politique de sécurité

## Signaler une faille

N'ouvrez pas de ticket public. Utilisez le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability**.

Indiquez la version ou le commit concerné, les étapes pour reproduire et l'impact que vous estimez.

## Versions prises en charge

Le projet n'a pas encore de version stable : seule la branche `main` reçoit des correctifs.
