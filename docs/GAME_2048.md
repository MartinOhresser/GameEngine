# 2048 : un jeu de glissement, fait de données

`games/game_2048` est un 2048 **sans une ligne de C++ propre au jeu** : tout est dans `game.json`, les préfabs et les scènes. Il sert à éprouver que les modules du moteur (`slide_merge`, `grid2d`, `gesture`, `phase`, `rules`, `tween2d`, `records`) se composent pour faire un jeu entier.

```
geplay games/game_2048/game.json
```

Flèches, W A S D (ou Z Q S D), ou un glissé du doigt ou de la souris : faire glisser les tuiles. R ou N, ou le bouton : nouvelle partie, à tout moment. Entrée ou C : continuer après 2048.

## Les règles, et ce qui les réalise

| Dans le jeu | Dans les fichiers |
| --- | --- |
| Un plateau de 4 × 4 cases, toujours en entier à l'écran | `grid2d.Grid` ; `camera2d.CameraFit` avec des marges pour l'interface |
| Un coup fait glisser toutes les tuiles ; deux tuiles égales font leur somme, une fois par coup | `slide_merge.SlideBoard` (`mode` 0) et `Tile` |
| Deux tuiles au départ, puis une par coup qui a changé quelque chose (un 2, un 4 une fois sur dix) | `rules.Watch` (`moves` vaut 0 au départ : lève `deal`) et `grid2d.SpawnOnEmpty` sur `deal` et sur `moved` |
| Un coup sans effet n'en est pas un : rien n'apparaît, rien n'est compté | `SlideBoard.moved_action` n'est levée que si une tuile a bougé |
| Le score est la somme des tuiles faites ; le meilleur est gardé | `SlideBoard.score`, `records.Record` (sauvegardé par `geplay`) |
| Une tuile a la couleur de sa valeur et son nombre écrit dessus | `sprite2d.FrameBind` (log2), `ui.Bind` avec `own` |
| Les tuiles glissent, apparaissent en grossissant, « sautent » quand elles fusionnent | `grid2d.GridPos.glide`, `transform2d.Scale` et `tween2d.Settle` |
| Victoire à 2048 : un message et **Continuer** ; la victoire n'est montrée qu'une fois | `rules.Watch` (`once`) → action `goal` → `phase.Transition` vers `won` ; `phase.ShowIn` |
| Plus de coup possible : fin de partie | `SlideBoard.stuck_action` → phase `lost` |
| Le plateau ne répond que pendant la partie | `phase.ActiveIn` |
| Nouvelle partie à tout moment | `scene_switch.GoToScene` sur l'action `new_game` (R, N, bouton) |
| Un glissé = une direction ; un appui bref = un clic | `gesture.Swipe` ; `ui.Menu` avec le pointeur |

## Les images et les scènes sont générées

```
python3 games/game_2048/tools/make_assets.py
```

écrit les images (`art/tiles.png`, `art/ui.png`), les préfabs, les scènes et les scénarios. La police est celle de `doodle_jump`.

## Les scénarios

`gerun games/game_2048/game.json --test` joue quinze scénarios sur des plateaux de test (`scenes/test_*.json` : la vraie scène avec les tuiles posées à la main, sans la partie au hasard) : fusion, une fusion par coup, les quatre directions, un coup sans effet, la tuile ajoutée après un coup, glissé et appui bref, victoire, continuer (clavier et bouton), plus de coup, nouvelle partie (touche et bouton), et le départ de la vraie scène.
